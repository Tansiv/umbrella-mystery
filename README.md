# 🌂 The Umbrella in the Rain: A Diary of Secrets

This is a mystery-themed interactive companion website for the novel **"The Umbrella in the Rain: A Diary of Secrets."**  
It immerses readers into a dark and suspenseful world filled with hidden clues, eerie characters, and a haunting past.  
Through atmospheric visuals, an interactive timeline, and concealed puzzles, users can explore the unfolding mystery behind Elias’s disappearance and Maya’s quest for truth.

---

## 🎯 Project Goals

- Allow readers to explore the world, events, and characters in a non-linear, mysterious fashion
- Deliver an immersive experience using atmospheric design and interactive storytelling
- Introduce hidden elements (Easter eggs, puzzles, secret pages) to deepen user engagement

---

## 🧩 Website Sections

| Page | Description |
|------|-------------|
| `index.html` | Landing page with rain animation and teaser |
| `timeline.html` | Scrollable timeline of major events from the story |
| `characters.html` | Character bios with flip-card effects and hidden facts |
| `clues.html` | Puzzle and clue area for readers to unlock secrets |
| `about.html` (optional) | Author or book background |
